#핵심 파일

#core/

파일 역할
interview.ts 면접 흐름. 한 번에 끝까지(interview), 한 단계씩(runChallenge, nextChallenge)
stages.ts 단계 구현: 검문소 분류기, 서류(흔들리는 항목 3표, 통과선 근처 재채점, "없다" 재확인), 1·2차 출제·실행·채점, 최종 공격 편성
gate.ts 보안 검문소 L1(형식·크기)·L2(정규식 HARD/SOFT)
scoring.ts 통과선, 인용 검증, 다수결, 점수 계산. 점수는 모델이 아니라 여기서 낸다
detectors.ts 코드 탐지기: canary, 명세 겹침, 유출 정규식, 반복, 강요 표식, 출력 약속, 도구 로그
contracts.ts 명세에 실제로 적힌 출력 약속만 남긴다
doc_review.ts 서류 체크리스트 파싱, 피드백-판정 연결, 재확인 반영
exam.ts 분기 고정 출제, 명세 해시, 시드
attack_variants.ts 공격 문구를 틀과 빈칸 값으로 조립
division.ts 명세의 model:로 체급 결정
engine.ts API 백엔드, 모델 ID, 가격표
prompts.ts 프롬프트 읽기, nonce, 데이터 감싸기, 지원자 시스템 프롬프트

#runner/

파일 역할
arena.ts 스킬이 부르는 CLI: start, next, status, list, submit, config, version. 번들 진입점
cli_engine.ts claude -p 백엔드. 키가 있으면 API로 바꾼다 (localLlm)
fs_exam_store.ts 출제분 파일 저장
summary.ts 단계 결과를 스킬이 읽을 요약으로
board.ts 제출물 만들기·검증, 순위 계산, promptsHash
board_cli.ts Actions용 sweep, 한 건 verify, rebuild
bundle_assets.ts prompts/·schemas/를 core/assets.generated.ts로
run.ts 개발용 로컬 실행기 (한 번에 끝까지, results/에 저장)
regress.ts 회귀 샘플을 N회씩 돌려 기대 결과와 비교
rejudge.ts 저장된 응답은 두고 1·2차 채점만 다시 (면접관 편차 측정)
compare_verdicts.ts 판정 비교 도구
export_core.ts core/를 다른 저장소로 복사

#스킬·패널

파일 역할
SKILL.md 진행자 규칙: 후보 고르기, 언어·모드, 단계 진행, 오류 처리
submit.md 제출 절차와 공개 동의, 배지
scenes.md 장면 레이아웃(로비·대기실·면접실·통지서)과 언어별 문구
register.tsx live.jsonl을 읽어 패널·상태줄·토스트를 그린다. /arena-room 명령

#빌드·실행·배포

npm ci                 # postinstall 이 core/assets.generated.ts 를 만든다
npm test               # pretest 로 번들을 먼저 빌드하고, 모델 호출 없이 core·runner 테스트
npm run typecheck
npm run build          # esbuild → plugins/arena/skills/apply/bin/arena.mjs
node runner/run.ts tests/sample_candidates/good_claude_subagent.md --lang ko   # 실제 모델 호출
node runner/regress.ts --runs 3                                                # 회귀 (비용 발생)
node runner/board_cli.ts rebuild                                               # 순위 다시 만들기
  • 개발에는 Node.js 24 이상(.ts 직접 실행). 설치한 스킬은 Node.js 20 이상.
  • 소스를 고치면 다시 빌드한 arena.mjs를 같은 커밋에 넣는다. 빠뜨리면 설치된 스킬이 예전 코드로 돈다.
  • prompts/나 schemas/를 고치면 프롬프트 해시가 바뀐다. 이전 결과도 계속 받으려면 이전 해시를 leaderboard/accepted_prompts.json에 넣는다.
  • 배포: main에 합치면 끝이다. 마켓플레이스·skills.sh·Pages가 main을 읽는다. 버전은 package.json, plugins/arena/.claude-plugin/plugin.json, runner/arena.ts의 ARENA_VERSION에 있고, 태그는 vX.Y.Z (CONTRIBUTING.ko.md).
  • 브랜치: feat/·fix/·docs/ 브랜치에서 PR로 main에 합친다. 통합 브랜치(develop)는 두지 않는다.
