# 💳 중량급 유료 티켓 결제 계획 (구현 전)

공개판 중량급(지원자 Claude Sonnet)은 지원자 엔진 비용을 운영자가 내기 때문에 티켓을 유료로 판다 (docs/08 4번, D-26). 결제 기능이 붙기 전까지 중량급은 닫아 둔다 (D-31, `ARENA_MIDDLE_OPEN`). 이 문서는 결제를 붙일 때의 계획이다. 아직 구현하지 않았다.

## 1. 정해야 할 것

| 항목 | 선택지 | 지금 생각 |
|---|---|---|
| 결제 대행사 | 토스페이먼츠 / Stripe | 국내 사용자 위주면 토스페이먼츠(카드·간편결제, 원화). 해외 사용자를 받으면 Stripe |
| 상품 | 티켓 1장 / 묶음(5장·10장) | 묶음 할인으로 결제 수수료 비중을 줄인다 |
| 가격 | 원가 기반 | 1인 완주 원가(중량 약 $1.2, 면접관 포함)는 상한이고 실제 평균은 서류에서 많이 끝나 더 낮다. 시즌 데이터로 평균 원가를 잰 뒤 정한다 |
| 유효 기간 | 시즌 종료까지 / 무기한 | 시즌 종료까지. 시즌 리셋(엔진 교체) 때 남은 티켓은 환불하거나 다음 시즌으로 넘긴다 |
| 하루 상한 | 유지 / 없앰 | 유지(하루 10장). 산 티켓이 많아도 하루에 쓰는 양은 묶어 대기열 독점을 막는다 |

## 2. 사용 규칙
- 중량급에 새 .md 를 낼 때 산 티켓을 1장 쓴다. 지금 티켓 표(`tickets`)의 "하루 사용 기록"은 그대로 두고, 보유 수량은 새 표에서 뺀다.
- 지금 규칙을 그대로 따른다: 통과해서 얻은 다음 단계 도전, 서버 오류 뒤 다시 시도(3번까지), 같은 분기 같은 .md 재제출은 티켓을 쓰지 않는다.
- 접수에 실패하면 쓴 티켓을 돌려준다 (지금 무료 티켓과 같은 방식).

## 3. 데이터

| 표 | 내용 |
|---|---|
| `orders` | 주문 id, 계정, 상품(장수), 금액, 통화, 상태(대기·결제됨·취소·환불), 결제 대행사 결제 키, 만든 시각 |
| `ticket_wallets` | 계정별 체급별 남은 유료 티켓 수 (주문 확정 때 더하고, 사용·환불 때 뺀다) |
| `wallet_ledger` | 증감 기록(주문 충전, 사용, 사용 취소, 환불). 잔액은 이 기록의 합과 맞아야 한다 |

모든 표에 RLS 를 켜고 정책은 두지 않는다 (지금 표와 같음).

## 4. 결제 흐름
1. 화면에서 상품을 고르면 서버가 주문(`대기`)을 만들고 금액을 서버가 정한다. 화면이 보낸 금액은 믿지 않는다.
2. 결제창(대행사 SDK)에서 결제한다.
3. 대행사가 결제 결과를 서버로 알린다(웹훅). 서버는 서명을 검증하고, 대행사 API 로 결제 금액·상태를 다시 조회해 주문 금액과 맞춘다.
4. 맞으면 한 트랜잭션에서 주문을 `결제됨`으로 바꾸고 지갑에 티켓을 더한다. 같은 웹훅이 여러 번 와도 한 번만 반영한다(주문 id 기준 멱등).
5. 화면은 주문 상태를 조회해 결과를 보여 준다.

## 5. 환불
- 쓰지 않은 티켓만 환불한다. 묶음은 남은 장수만큼 부분 환불한다.
- 전자상거래법상 청약 철회(구매 후 7일)를 안내하고, 쓴 티켓은 철회 대상에서 뺀다는 것을 결제 전에 알린다.
- 서버 오류로 면접을 마치지 못한 경우는 이미 티켓을 쓰지 않으므로 환불 대상이 아니다.

## 6. 열기 전에 필요한 것 (코드 밖)
- 사업자 등록, 통신판매업 신고, 대행사 가맹 심사
- 이용약관·환불 규정·개인정보 처리방침(결제 정보는 대행사가 보관, 우리는 주문·결제 키만)
- 세금계산서·현금영수증 처리 방식

## 7. 단계
1. 지갑·장부 표와 사용 규칙을 먼저 넣고, 운영자가 수동으로 티켓을 지급하는 화면으로 시험한다 (결제 없이 흐름 검증).
2. 대행사 테스트 모드로 결제·웹훅·환불을 붙인다.
3. 사업자·약관 준비가 끝나면 실결제로 바꾸고 `ARENA_MIDDLE_OPEN` 대신 "티켓 보유" 조건으로 중량급을 연다.

## 대안 (선택하지 않음)
- 중량급도 무제한급처럼 지원자 키(BYOK)로 열기: 결제 없이 바로 열 수 있지만 "운영자 키로 공정하게 같은 조건" 이라는 중량급의 의미가 무제한급과 겹친다. 결제 준비가 길어지면 임시로 검토한다.
